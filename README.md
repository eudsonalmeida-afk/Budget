# Meu Budget Feliz v2

Substitua no repositório os arquivos `index.html`, `style.css` e `script.js`.

## Alterações
- lançamento rápido por botões;
- data corrente automática;
- salário e despesas separados por mês;
- abertura automática no mês atual;
- navegação entre meses;
- filtros e totais por banco;
- observação opcional;
- exclusão de gastos;
- exportação mensal em CSV;
- armazenamento local no navegador.

## Importante
Os dados ficam no localStorage do navegador. Eles não sincronizam entre aparelhos e podem ser apagados ao limpar os dados do navegador.
